# hack-9923a583-ctrl-c
Hackathon team repository for ctrl+C

## Backend: каталог подрядчиков

Первый этап бэкенда использует SQLite. Схема хранит профили в `vendors`, а списки категорий, форматов, языков и занятых дат — в JSON-столбцах.

Когда Python 3.10+ установлен, из корня проекта создайте и заполните локальную базу:

```powershell
python backend/import_dataset.py
```

По умолчанию скрипт читает `hackathon dataset anonymized .csv` в корне проекта и создаёт `backend/data/vendors.sqlite3`. Повторный импорт обновляет профили с теми же ID. Путь к CSV или базе можно переопределить флагами `--csv` и `--db`.

### API подбора

Установите зависимости и запустите сервер из корня проекта:

```powershell
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --reload
```

Фронтенд отправляет `POST http://localhost:8000/api/recommend` (также доступен `/api/recommendations`):

```json
{
  "city": "Алматы",
  "date": "2026-11-14",
  "event_format": "свадьба",
  "category": "Ведущий",
  "budget": 1000000,
  "duration": 5,
  "language": "русский"
}
```

Город и категория, занятость в дату, бюджет, формат, язык и длительность — фильтры допуска. Город не совпал — профиль не рассматривается; цена ниже бюджета не приносит дополнительных баллов. После фильтрации сортировка детерминирована: сначала баллы за формат, язык, соответствие лимита длительности и конкретные слова в описании, затем ID профиля. Ответ соответствует текущему фронтенду: `status` (`success`, `category_not_found` или `no_matches`) и карточки в `results`. Для подключения текущего `js/api.js` выключите `MOCK_MODE` и задайте `API_URL` как `http://127.0.0.1:8000/api/recommend`, если фронтенд запущен отдельно (например, через Live Server). `GET /api/health` — проверка доступности сервера.
