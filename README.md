# hack-9923a583-ctrl-c
Hackathon team repository for ctrl+C

## Backend: каталог подрядчиков

Первый этап бэкенда использует SQLite. Схема хранит профили в `vendors`, а списки категорий, форматов, языков и занятых дат — в JSON-столбцах.

Когда Python 3.10+ установлен, из корня проекта создайте и заполните локальную базу:

```powershell
python backend/import_dataset.py
```

По умолчанию скрипт читает `hackathon dataset anonymized .csv` в корне проекта и создаёт `backend/data/vendors.sqlite3`. Повторный импорт обновляет профили с теми же ID. Путь к CSV или базе можно переопределить флагами `--csv` и `--db`.

### API подбора

Установите зависимости и запустите сервер из корня проекта:

```powershell
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --reload
```

Фронтенд отправляет `POST http://localhost:8000/api/recommend` (также доступен `/api/recommendations`):

```json
{
  "city": "Алматы",
  "date": "2026-11-14",
  "event_format": "свадьба",
  "category": "Ведущий",
  "budget": 1000000,
  "duration": 5,
  "language": "русский"
}
```

Город и категория, занятость на дату, бюджет, формат, язык и длительность — фильтры допуска. Не прошедший обязательное условие кандидат исключается, цена ниже бюджета не даёт дополнительных очков. Ранжирование вынесено в `backend/matching.py`: баллы начисляются за город (10), категорию (10), свободную дату (15), бюджет (20), формат (20), заданный язык (10), длительность (до 15) и смысловые совпадения в описании (до 10). Итог нормализуется до 100, равные оценки упорядочиваются по ID; наружу выдаются максимум три карточки. `backend/recommender.py` формирует статусы и объяснение пустых результатов. Ответ соответствует текущему фронтенду: `status` (`success`, `category_not_found` или `no_matches`) и карточки в `results`. `GET /api/health` — проверка доступности сервера.
